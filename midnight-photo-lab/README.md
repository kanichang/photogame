# 午前二時の現像所 — Midnight Photo Lab

閉店後の小さな写真店で、正体の分からないフィルムを一工程ずつ美しい写真へ仕上げる、放置・自動化対応のブラウザゲームです。

## 起動方法

`index.html` を直接ブラウザで開いてください。ビルド、サーバー、インターネット接続、外部素材は不要です。

## ゲームの基本操作

1. 受付から暗いフィルムが現像槽へ運ばれるのを待ちます。
2. 「操作可能」と光る設備そのものをクリックします。共通の作業ボタンはありません。
3. 現像、乾燥、スキャン、色補正、印画紙、額装の短い固有操作で品質を高めます。
4. 完成写真の売上で、自動化・高速化・容量増加を購入します。
5. 手作業で月光ゲージを満たすと、45秒間の満月モードが始まります。

## 6工程の操作

- **現像槽**：進行針が淡い適正範囲に入ったら「引き上げる」または `Space`。
- **乾燥機**：「弱風」「強風」または左右キー / `A`・`D` で湿度を適正範囲に保つ。
- **スキャナー**：走査光が通り過ぎる前に、写真上のホコリをクリック。
- **色補正卓**：明るさと色温度を動かし、写真ごとの雰囲気へ合わせて決定。
- **プリンター**：公開されたテーマとタグを見て、光沢紙・マット紙・温調紙から選択。
- **額装台**：即時プレビューを見ながら、写真に合う額縁を選択。

操作に失敗しても写真は失われません。途中で `Esc` を押した場合も通常評価で次工程へ進みます。

## 実装機能

- 段階的なテーマ・画像・レアリティ公開と、依頼人の短い物語
- 通常、古い、濡れた、白黒の特殊フィルム
- 0〜100の品質スコア、工程別評価、C〜Sランク、品質連動の売値
- 固有グラフィックと操作を持つ6設備
- 月光ゲージ、45秒の満月モード、自動設備の介入チャンス
- 完成画像、内訳、全工程評価、依頼人の反応を示す大型完成演出
- 自動化、高速化、容量増加、最大50枚のアルバム、店内展示
- 新着順・最大6件の縦型「夜の記録」
- 5秒ごとの自動保存、既存セーブ移行、最大2時間のオフライン進行
- 効果音、モーション軽減、キーボード操作、設定画面

## キーボード

- `1`〜`6`：設備を選択
- `Space`：選択した操作可能設備を開く / 現像写真を引き上げる
- `Esc`：ミニゲームを通常評価で完了 / 完成・プレビューパネルを閉じる
- `Enter`：現在の決定または完成パネルを閉じる
- 左右キー / `A`・`D`：乾燥機の風量、色補正の明るさ
- `Tab`：操作可能要素間を移動

## セーブデータ

従来と同じ `midnight-photo-lab-save-v1` を使用します。旧データの所持金、設備、完成数、アルバムを保ったまま、品質、公開段階、フィルム種別、月光ゲージなどの不足値を読み込み時に補完します。

「設定」タブから即時保存、モーション設定、効果音設定、セーブ削除を利用できます。
