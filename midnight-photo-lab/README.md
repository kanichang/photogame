# 午前二時の現像所 — Midnight Photo Lab

閉店後の小さな写真店を舞台にした、15〜30分向けの放置・自動化ゲームのブラウザプロトタイプです。

## 起動方法

`index.html` をダブルクリックし、任意のモダンブラウザで開いてください。ビルド、サーバー、インターネット接続は不要です。

## ゲームの基本操作

1. 5〜8秒ごとに届くフィルムを待ちます。
2. 店内の設備を選択し、右側の「作業する」を押します。
3. 現像槽、乾燥機、スキャナー、色補正卓、プリンター、額装台の順に作業します。
4. 完成写真の売上で、自動化・高速化・容量増加を購入します。
5. 25枚を完成させ、全工程を自動化するとプロトタイプの目標達成です。

設備は数字キー `1`〜`6` でも選択でき、`Space` で作業を開始できます。写真のプレビューは `Esc` で閉じられます。

## 実装済み機能

- 一意のID、テーマ、レアリティ、シード、工程、売値を持つフィルム
- 工程ごとの待機、処理、完了、移動待ちと容量制御
- 6設備の手動操作、自動化、高速化（3段階）、容量増加（2段階）
- 12テーマ・4レアリティのシード付きCanvasピクセルアート
- 最新50枚のアルバムと拡大プレビュー
- 雨、月、機械、スキャナー、プリンターなどの段階的アニメーション
- 最大6件のイベントログ、キーボード操作、モーション軽減
- Web Audio APIによる任意の効果音（初期状態はオフ）
- 5秒ごとのlocalStorage自動保存と復元
- 全工程自動化時のみ、最大2時間分を概算するオフライン進行
- 25枚完成かつ全自動化の目標演出

## セーブデータの削除方法

「設定」タブの「セーブデータを削除して最初から始める」を押し、確認ダイアログで承認してください。開発者ツールから削除する場合のキーは `midnight-photo-lab-save-v1` です。

## 今後製品版に追加できる機能

- 注文主ごとの短い物語と常連客
- 写真テーマ、機械、店内装飾の追加
- より精密なオフライン工程シミュレーション
- 蒸気、雨音、機械音を重ねた環境音設計
- 実績、統計、アクセシビリティ設定の拡充
- Steam向けセーブ同期とコントローラー対応

プロトタイプでは、オフライン進行を全工程のボトルネック時間による概算にし、写真生成を6種の構図テンプレートの組み合わせに簡略化しています。
